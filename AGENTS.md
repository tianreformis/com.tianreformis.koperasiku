# KoperasiKu — Agent Guide

## Architecture

- **Flutter app** (single package, no monorepo) — entry: `lib/main.dart`
- **State**: Riverpod (`flutter_riverpod`) + legacy `provider` — see `lib/providers/`
- **Routing**: Static named routes in `lib/config/routes.dart` (not GoRouter)
- **Firebase**: Auth, Firestore, Storage, Messaging — options in `lib/config/firebase_options.dart` (generated by `flutterfire_cli`)
- **Firestore collections**: `users`, `simpanan`, `pinjaman`, `angsuran`, `settings` — see `lib/config/constants.dart`
- **Sorting**: All Firestore queries sorted in Dart (no `.orderBy()`) — no composite indexes needed

## Commands

```powershell
flutter pub get                        # install deps (first step)
flutter devices                        # check available devices
flutter run -d <device-id>             # run app
flutter run -t dummy_data.dart         # seed Firestore with test accounts
flutter build apk --debug              # debug APK in build/app/outputs/flutter-apk/
flutter test                           # run tests
```

## Linting & Style

- Lint rules: `flutter_lints` + `prefer_const_constructors`, `prefer_const_literals_to_create_immutables`, `avoid_print`, `prefer_single_quotes`
- Run: `dart analyze` (no separate lint script)
- The seeder (`dummy_data.dart`) uses `print` — exempt from `avoid_print` by role (it is a CLI script, not app code)

## Testing

- Single widget test at `test/widget_test.dart` — outdated (references counter app, not current app)
- Run: `flutter test`

## Setup Gotchas

| Issue | Fix |
|-------|-----|
| Flutter SDK in path with spaces | Copy to e.g. `C:\flutter` — native asset hooks crash otherwise |
| Missing `google-services.json` | Download from Firebase Console → `android/app/` |
| `firebase_options.dart` missing | Run `dart run flutterfire_cli:configure --project=<project-id>` |

## Conventions

- **Locale**: `id_ID`, currency Rp, date `dd/MM/yyyy`, language Indonesian
- **Theme**: Teal primary (`#0D6E6E`), Poppins font via `google_fonts`
- **Models**: `fromMap`/`toMap` pattern, `copyWith` method
- **Lint**: `prefer_single_quotes` is active — use single quotes for strings
